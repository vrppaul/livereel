# livereel's own sounds

Every file here is under Creative Commons Zero (CC0 1.0, http://creativecommons.org/publicdomain/zero/1.0/), as its source says, and written as Ogg Vorbis for livereel.

The click and the ending are Kenney's (www.kenney.nl), each made quieter (`volume=0.35`):

| File | Kenney's pack | Kenney's file |
|---|---|---|
| `click.ogg` | UI Audio (UI SFX Set) | `Audio/mouseclick1.ogg` |
| `ending.ogg` | Interface Sounds 1.0 | `Audio/confirmation_002.ogg` |

Each keyboard in `keys/` is four single strikes, each cut out of its recording with quiet on both sides and faded at its ends. A keyboard's strikes share one peak, and each keyboard is as loud as the others where it counts: a line typed on it is as loud, on the whole, as on the click livereel's keys were before.
